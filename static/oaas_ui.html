Continue + éditeur (Code OSS, Cursor, VSCodium)

OAAS peut écrire le bloc modèle dans ~/.continue/config.yaml (format Continue YAML) et lancer ton éditeur sur le dossier projet (chemin ci-dessus, sous $HOME uniquement). Ce n’est pas un clone de Cursor : c’est le pont pratique vers l’extension Continue déjà installée.
